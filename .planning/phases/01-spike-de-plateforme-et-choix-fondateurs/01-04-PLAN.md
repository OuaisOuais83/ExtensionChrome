## Edge Assumptions (no SPEC.md for this phase)

- The image endpoint only updates an existing probe row; an unknown or malformed id still gets the 1x1 PNG (200) for valid filenames and 404 for invalid ones, and never creates a row.
- IPv6 or missing `CF-Connecting-IP` counts as "other"; only the boolean classification is kept, never the address.
- Probe rows have no expiry in phase 1 (no personal data, tiny volume); purge arrives with the phase 2 cron.
- Migrations are applied in the probe test file's own beforeAll (no global setup file): it is the only suite that uses D1 in this phase.
