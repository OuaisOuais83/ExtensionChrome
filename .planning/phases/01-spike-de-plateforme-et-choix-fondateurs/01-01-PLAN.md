## Edge Assumptions (no SPEC.md for this phase)

- All dependencies of the whole phase are installed here, once, so the lockfile is written once and every later plan reuses the vetted set.
- `apps/server/.dev.vars` is a local, gitignored file. Task 2 writes it with the two development values so that `wrangler types` declares `SPIKE_ACCESS_CODE` in `Env` from the start; the committed example file (`.dev.vars.example`) arrives with the smoke script in plan 02.
- The log seam accepts only whitelisted metadata. Fields that fail the whitelist are dropped and replaced by a single `log_rejected` event; content never reaches the console.
- Logs are not persisted by the service: `observability.enabled` is false (Workers Logs off), no Logpush job and no tail consumer exist; `wrangler tail` is a live stream the service does not store. Retention inside the host beyond these features is not assessed and is not claimed. This is the reading of PLAT-04's log clause ("journaux non persistés") that the owner validates at the plan 07 Task 1 checkpoint.
