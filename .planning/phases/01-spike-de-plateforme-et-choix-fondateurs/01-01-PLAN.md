## Phase Goal

**As a** porteur du projet, **I want to** tester un connecteur sur chaque surface Claude et figer les choix irréversibles, **so that** je bâtis sur du vérifié.

(ROADMAP, phase 1 : « En tant que porteur du projet, je veux tester un connecteur sur chaque surface Claude et figer les choix irréversibles, afin de bâtir sur du vérifié. »)

This plan delivers the first slice of that story: a Claude-compatible OAuth + MCP Worker whose `ping` answers end to end, proven locally inside the container. Real-account measurements and the irreversible choices come in plan 03.

<objective>
Build the walking-skeleton Worker: one Cloudflare Worker that is at the same time the OAuth 2.1 authorization server Claude expects (CIMD with DCR fallback, PKCE S256, RFC 8414 / 9728 discovery, loopback redirects for Claude Code, form-encoded token endpoint, refresh rotation) and a stateless MCP server serving both protocol eras, with one read-only `ping` tool that names the linked account. Prove it with an in-workerd end-to-end test, a Claude-specific conformance suite, and a real-HTTP smoke script against `wrangler dev`.

Purpose: the authorization server is the riskiest choice of the stack and has never met a real Claude (STATE.md blocker). Everything in plans 02-03 and phase 2 sits on this slice.
Output: pnpm monorepo scaffold, `apps/server` Worker, tests, smoke scripts, committed lockfile.
</objective>

## Edge Assumptions (no SPEC.md for this phase)

- The spike identity is one fixed account (`SPIKE_ACCOUNT_EMAIL`, default `porteur@relay.invalid`); every Claude the owner connects binds to it. KV `userId` = `spike_` + first 24 hex chars of SHA-256(`relay-spike:` + lowercased email).
- `SPIKE_ACCESS_CODE` shorter than 16 characters, or absent, refuses every approval (fail-closed). Wrong code re-renders the page with HTTP 400 and does not consume the consent handle.
- Scopes: the page grants the requested scopes intersected with `mcp:tools` and `offline_access`; the MCP handler does not enforce scopes in phase 1 (advertised only, per library docs).
- Access tokens live 900 s in the spike so that real Claude refreshes during a session; refresh grants keep the library default (30 days).
- GET and DELETE on `/mcp` are answered by the SDK stateless legacy leg (405); that is expected, not a failure.
- Requests to `/mcp` whose Host header is not the `PUBLIC_BASE_URL` host are refused before the SDK; requests without an Origin header are allowed (Anthropic's cloud sends none).
- Metadata fields that fail the log whitelist are dropped and replaced by a single `log_rejected` event; content never reaches the console.
